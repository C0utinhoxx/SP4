Análise de complexidade com os dados atuais

As operações abaixo são calculadas pelo backend Python usando a quantidade real de sessões armazenadas agora — assim dá para mostrar, no vídeo, o que acontece com o número de operações quando n cresce.

Onde no códigoOperaçãoBig-OCom as sessões atuais

O que acontece quando n aumenta?

  • O(1) — inserir no fim da lista: cresce 1 a 1, nunca muda (append).
  • O(n) — busca linear e estatísticas: se n dobra, as operações dobram.
  • O(log n) — busca binária: n dobra e só +1 comparação (divide pela metade).
  • O(n log n) — Merge/Quick: cresce um pouco mais que linear.
  • O(n²) — Bubble/Selection/Insertion: n dobra e as operações multiplicam ~4x.

Fluxo Interface → Backend

  1. Interface Web envia fetch() (JSON) para a rota Flask.
  2. Flask lê a requisição e chama o repositório (lista de objetos).
  3. Repositório executa busca/ordenação/estatística em Python.
  4. Backend devolve JSON com dados + métricas de operações.
  5. Interface renderiza o resultado na tela.

Backend: Python 3 + Flask  |  Estruturas: dataclass, lista, dicionário  |  Busca: linear O(n) e binária O(log n)  |  Ordenação: Bubble, Insertion, Selection, Merge e Quick implementados manualmente.
